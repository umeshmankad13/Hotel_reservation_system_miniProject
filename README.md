# Hotel_reservation_system_miniProject
# Hotel Management System (JDBC)

## Features
- Reserve Room
- View Reservations
- Update Reservation
- Delete Reservation
- MySQL + JDBC

## Tech Stack
- Java
- JDBC
- MySQL
- IntelliJ IDEA

## How to Run
1. Import project in IntelliJ
2. Configure MySQL DB
3. Update DB credentials
4. Run main class
